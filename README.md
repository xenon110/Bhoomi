# Bhoomi

A modern, offline-first digital companion for Indian farmers.

## Overview
Bhoomi empowers farmers with intelligent crop diagnosis, real-time mandi prices, localized weather outlooks, farm diary management, and rental equipment listings.

- **Offline-First & Cloud Sync**: Powered by Turso Edge SQLite Cloud DB.
- **Multilingual**: Native Hindi and English support.
- **Crop Doctor**: AI-driven visual disease and pest recognition with voice advisory.
- **Mandi Arbitrage**: Real-time MSP tracking and regional market price comparison.
- **Farm Diary & Ledger**: Track sowing, irrigation, harvest, and farm expenditures.
